# Shaxsiy Reja
Kartalar, kasholak, oylik va eslatmalar. Ma'lumotlar faqat telefoningiz brauzerida saqlanadi.

## GitHub Pages orqali joylash
1. github.com da yangi repo oching (masalan `reja`), Public.
2. Shu papkadagi barcha fayllarni yuklang (index.html, sw.js, manifest.webmanifest, icons/).
3. Settings → Pages → Branch: `main` / `(root)` → Save.
4. 1-2 daqiqadan so'ng `https://<username>.github.io/reja/` manzilida ochiladi.

## Telefonga o'rnatish
- Android (Chrome): sahifani oching → ⋮ → "Ilovani o'rnatish" / "Bosh ekranga qo'shish".
- iPhone (Safari): Ulashish tugmasi → "Bosh ekranga qo'shish".
